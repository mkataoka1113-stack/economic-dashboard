実質GDPと名目GDP
今日のニュースで「4〜6月の実質GDP年率1.1%増」「名目GDP687.7兆円で過去最高」とありましたね。GDP（国内総生産）は、一定期間に国内で生み出されたモノやサービスの付加価値の合計額を示す経済指標です。このうち『実質GDP』は物価変動の影響を除いて計算されるため、経済活動が実際にどれだけ増えたか、つまり『経済の量的な成長』を表します。一方、『名目GDP』は物価変動の影響を含んだ金額で、経済活動の『金額的な規模』を示します。例えば、物価が上昇しただけでは名目GDPは増えますが、実質GDPはほとんど変わらない、ということが起こり得ます。投資家は両方を見て、経済の健全性を判断します。
